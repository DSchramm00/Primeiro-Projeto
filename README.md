# First Project App

Meu primeiro projeto utilizando Java e Spring Boot.

Uma API REST para gerenciamento de produtos, com operações de cadastro, consulta, atualização e exclusão.

## Tecnologias utilizadas

- Java
- Spring Boot
- Spring Data JPA
- Maven
- Banco de dados H2
- JUnit e Mockito

## Funcionalidades

- Cadastrar produtos
- Consultar produtos pelo código
- Atualizar produtos
- Excluir produtos
- Validar dados
- Tratar exceções
- Testes automatizados

## Como executar

## No terminal, execute:

./mvnw spring-boot:run

## No Windows:

mvnw.cmd spring-boot:run
